# Security

LawScape is a static, offline-capable browser game. It does not need a backend,
account, analytics service, or external API.

To report a vulnerability, please use GitHub's private vulnerability reporting
feature for the repository rather than opening a public issue. Do not include
private client information or real confidential legal facts in a report.

Saved game progress is stored only in the player's browser using `localStorage`.
It is not encrypted and should not contain sensitive information.
